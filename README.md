# MyPlans

Meet halfway, effortlessly. Add where everyone is, see the fair meeting zone you can all drive to, and find things to do inside it.

- Landing page + planner (React, TypeScript, Vite, Leaflet)
- Meeting zone = overlap of everyone's reach, highlighted on the map
- Real car routes and drive times (OSRM), place search and suggestions (Nominatim, Photon), places from OpenStreetMap
- Results ranked by fairness, shown as sliding cards
- No API keys, no sign-up; plans are saved in your browser and shareable by link

## Develop

```bash
npm install
npm run dev
```
